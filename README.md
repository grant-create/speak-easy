Learn a Language (Usage-First Outline)
Goal: Learn the most useful parts of a language first, use them immediately, and expand gradually.
Instruction for AI: “Teach <language> following this outline. Use natural phrasing as the language actually uses it, not direct English translations. Prioritize usefulness and real spoken usage.”

1. Sentence Building Basics
* Basic word order
* How statements work
* How questions are formed
* How to say “not” (negatives)
(Only what’s needed to start speaking — no deep grammar.)

2. Core Social Phrases (Natural Usage)
* Hello / goodbye
* Please / thank you
* Excuse me / sorry
* How are you?
* I’m doing well, and you?

3. Pointing & Location Words
* this / that
* here / there
* this one / that one
(Used with gestures and in real situations.)

4. High-Power Verbs (Present Tense First)
* to be
* to have
* to want
* to like
* to know
* to go
Taught using short, reusable sentence patterns.

5. Asking for Things & Information
* I would like…
* Can I have…
* Where is…
* Do you have…?
* How do you say…?
Focus on polite, natural phrasing.

6. Conversation Repair & Survival Phrases
(Used when you get stuck — essential for real conversations.)
* I don’t understand
* Please repeat
* Slower, please
* What does this mean?
* Can you help me?
These enable continued conversation even with limited vocabulary.

7. Minimal Vocabulary Expansion
Only words that plug into existing sentence patterns:
* people
* places (bathroom, hotel, store)
* common objects
Avoid large word lists.

8. Conversation Building
* short back-and-forth exchanges
* confirming understanding
* simple reactions (yes, no, maybe, okay)
Practice combining everything learned so far.

9. Time (Practical, Not Academic)
* talking about the past (before, yesterday)
* talking about the future (later, tomorrow, going to)
Focus on meaning first; accuracy improves with use.
